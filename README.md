# 三角線（Misumi Line）リアルタイムナビ v24

## 今回の方向転換
- 4画面の横スワイプ型から、**固定ヘッダー＋固定下部ナビ＋画面内スクロール**へ変更
- メイン画面を「列車ナビ」に再設計
- 横型路線図をやめ、スマホ向けの**縦型リアルタイム路線図**へ変更
- 列車アイコンに「次駅＋到着予定時刻＋定刻/遅延」を表示
- 列車をタップすると詳細を下から表示
- 駅をタップすると、その駅からの次列車を表示
- **熊本駅をタップすると、その先につながる列車一覧を表示**
- 接続専用画面も追加し、「三角線到着→接続列車」を1つの流れで確認
- 時刻表は独立した補助画面として残置
- 地図はv23の外部CDN非依存SVG方式を継続
- プロトタイプの接続列車時刻はUI検証用サンプルであり、正式データではありません

## UIコンセプト
「NAVITIME ↔ トレインナビを往復する」負担を減らし、
**乗る前 → 今どこ → 何時に来る → 熊本で何につながる**
を一続きで確認できる三角線の日常利用者向けナビを目指す。
