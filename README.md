# JR九州 三角線列車情報アプリ 簡易版Webプロトタイプ v2

## 今回の修正
1. 列車位置画面
   - 左を三角、右を宇土に反転
   - 駅間隔を縮小
   - 列車アイコン上に「平常運転」「5分遅れ」等を表示

2. 地図
   - 宇土〜三角9駅の公開緯度経度を反映
   - 地図の表示範囲を9駅全体に自動フィット
   - 列車位置も緯度経度で表示
   - 列車アイコン付近に運行状況を表示

3. 時刻表
   - 2026年7月時点の公開時刻表をもとに、駅別・方向別に収録
   - A列車で行こうは「A列車※」として表示（運転日に注意）

## 対象駅
三角 ← 波多浦 ← 石打ダム ← 赤瀬 ← 網田 ← 肥後長浜 ← 住吉 ← 緑川 ← 宇土

## 注意
- 列車位置・遅延はデモ用モックデータです。
- 実際の運行情報はJR九州提供データへの切替が必要です。
- 時刻表は確認用の固定データで、ダイヤ改正時には更新が必要です。
- 地図上の線は各駅を直線で結んだ簡易表示です。鉄道線形そのものの精密トレースではありません。

## v13 変更点（熊本・西熊本・川尻・富合の時刻表）

【時刻表】に以下4駅を追加しました。

- 熊本
- 西熊本
- 川尻
- 富合

三角方面は、JR九州公式の駅別時刻表から「三角行」を抽出しています。
A列車で行こう1号・3号は熊本駅には表示し、西熊本・川尻・富合は通過するため表示しません。

熊本方面は、三角線から熊本方面へ直通する列車を、宇土駅の上り時刻と
富合・川尻・西熊本の公式時刻表を照合して抽出しています。
A列車で行こう2号・4号は宇土〜熊本間でこれら3駅を通過するため表示しません。

熊本駅で「熊本方面」を選んだ場合は、熊本が終点である旨を表示します。

※JR九州公式時刻表には運休・時刻変更の可能性がある旨の案内があります。
正式運用ではJR九州から提供・許諾されたデータ連携を優先してください。
