# JR九州 三角線列車情報アプリ 簡易版Webプロトタイプ v16

## 今回の主な修正

### 1. 起動画面（スプラッシュ）を追加
- アプリ起動時に、提供いただいた「三角線リアルタイムナビ」ロゴを画面中央に約2.4秒表示します。
- その後、自動でホーム画面（運行状況）へ遷移します。

### 2. オンラインミーティングの指摘を反映
- 文字サイズを全体的に拡大しました。
- 【時刻表】の見やすさを改善しました。
  - 駅選択と方面切替を上部固定
  - 一覧部分のみ内部スクロール
  - 各列車をカード風に表示
- 速度表示は、【運行状況】【列車位置】【地図】のUIから削除しました。
- 時間どおりの列車は「定刻」と表示します。
- 終点（三角駅）に到着している列車は「終点到着」と表示し、次駅到着予定は表示しません。
- D&S列車のイメージとして、A列車で行こうの写真を【運行状況】カードへ表示しました。

### 3. 列車データの扱い
- 8031D
  - 富合〜宇土間を走行中として表示
  - 次駅：宇土
  - 次駅到着予定：10:31
  - 運行状況：定刻
- 527D
  - currentStation / nextStation / nextStop がすべて三角
  - 三角駅到着済み（終点到着）として表示
  - 次駅到着予定は表示しない

### 4. 列車位置情報・地図の今後の前提
- 実運用では、JR九州から提供される証明書付きデータ取得を前提としています。
- 地図線形については、国土数値情報や正式な線形データへ切り替える想定です。

### 5. 時刻表について
- 熊本〜三角の13駅を引き続き収録しています。
- 熊本駅での鹿児島本線接続表示は、今後の拡張候補として注記を追加しています（今回は仮データを作らず、誤案内を避けています）。

## v17 変更点
- 起動時ロゴを透明背景PNG版へ差し替え。
- 【地図】の路線を、駅間の直線ではなく国土数値情報 `N02-25_RailroadSection` の細かな緯度経度で描画。
- 熊本〜宇土は国土数値情報上の「鹿児島線」、宇土〜三角は「三角線」のJR九州線形を抽出。
- 国土数値情報から抽出した表示用データを `route-geometry.js` に格納し、ローカルHTMLでも読み込めるようにした。
- 駅マーカーおよびJR九州サンプル列車の緯度経度表示は従来どおり保持。

※ `route-geometry.js` は、ユーザー提供の `N02-25_RailroadSection(2).geojson` をもとに熊本〜三角周辺のみ抽出したものです。
