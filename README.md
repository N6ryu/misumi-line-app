# JR九州 三角線列車情報アプリ 簡易版Webプロトタイプ v2

## 今回の修正
1. 列車位置画面
   - 左を三角、右を宇土に反転
   - 駅間隔を縮小
   - 列車アイコン上に「平常運転」「5分遅れ」等を表示

2. 地図
   - 宇土〜三角9駅の公開緯度経度を反映
   - 地図の表示範囲を9駅全体に自動フィット
   - 列車位置も緯度経度で表示
   - 列車アイコン付近に運行状況を表示

3. 時刻表
   - 2026年7月時点の公開時刻表をもとに、駅別・方向別に収録
   - A列車で行こうは「A列車※」として表示（運転日に注意）

## 対象駅
三角 ← 波多浦 ← 石打ダム ← 赤瀬 ← 網田 ← 肥後長浜 ← 住吉 ← 緑川 ← 宇土

## 注意
- 列車位置・遅延はデモ用モックデータです。
- 実際の運行情報はJR九州提供データへの切替が必要です。
- 時刻表は確認用の固定データで、ダイヤ改正時には更新が必要です。
- 地図上の線は各駅を直線で結んだ簡易表示です。鉄道線形そのものの精密トレースではありません。


## v3 調整内容
- 地図上の列車アイコンの位置ずれを修正
  - Leaflet の緯度経度位置とCSSの二重オフセットを解消
  - アイコン下端中央が列車の緯度経度に一致
- 列車の移動速度を現実的な値に変更
  - 三角方面：45 km/h
  - 宇土方面：40 km/h
  - 3秒ごとに固定距離を進めるのではなく、駅間の実距離から進捗量を計算
- 【列車位置】タブと【地図】タブは同じ positionIndex から位置を算出
  - 2画面で列車位置が一致
- 列車位置は必ず隣接駅の緯度経度を線形補間して算出
  - プロトタイプ上、列車が路線表示から外れない


## v4 統合内容
- 元田さん案を踏襲し、下部4メニューUIを維持。
- 松永さん案を取り入れ、列車位置画面の路線図下に「路線上の列車運行情報」を追加。
- 田内さん案の考え方を取り入れ、縦移動より明確に横移動が大きい場合だけページを切り替える。
- 列車位置の横スクロール中はページ切替を無効化。

## v5 変更点

  「4つの機能が常に見える」「現在選択中の機能が分かる」

## v6 変更点（沿線背景デザイン）

4つの画面をスワイプするたびに、三角線沿線を印象づける背景へ切り替わるようにしました。

- 運行状況：三角駅
- 列車位置：海のピラミッド
- 地図：長部田海床路
- 時刻表：住吉のあじさい

写真はそのまま全面表示するのではなく、CSSで彩度・コントラスト・明るさを少し調整し、
白い半透明レイヤーとガラス調カードを重ねることで、少しイラスト調で柔らかい印象にしています。
情報の読みやすさを優先し、背景が文字や地図を邪魔しないようにしています。

画像ファイルは `assets/` フォルダに格納しています。


## v7 デザインリライト

生成イメージに合わせ、スマートフォン表示を中心にUIを再設計しました。

- 写真を全面背景にせず、各画面上部に大きな「沿線ビジュアル」として表示
- 三角駅、海のピラミッド、長部田海床路、住吉のあじさいが切れすぎない高さ・位置に調整
- 情報カードを写真の下端へ少し重ね、スマホアプリらしいレイヤー感を追加
- 下部メニューを「アイコン＋文字」に変更
- 選択中メニューを青い大きなボタンとして明確に表示
- 列車位置、地図、時刻表の既存機能と誤スワイプ防止処理を維持
- 列車アイコンのCSSアニメーションを維持
