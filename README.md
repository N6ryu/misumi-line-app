# 三角線（Misumi Line）リアルタイムナビ v23

## v23 地図表示の抜本修正
- Leaflet / unpkg.com への依存を完全に削除
- OpenStreetMapタイルの外部読込も削除
- 熊本〜三角の路線をアプリ内蔵SVGとして描画
- 各駅間10中間点の軽量路線データを使用
- JR九州サンプルの緯度経度から列車アイコンをSVG上へ配置
- 走行中の列車アイコンに小さな動きを付与
- 外部CDNが学校ネットワークで遮断されても路線図自体は表示可能
- 起動ロゴ、運行状況、列車位置、時刻表、背景画像は従来仕様を継続

### 補足
v23の「地図」は、背景地図タイルではなく、緯度経度に基づく軽量な路線図です。
まず地図表示障害を確実に切り分けることを優先しています。
